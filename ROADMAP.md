# Hawsub Roadmap

## Phase 1 — Working foundation
Goal: reliable pyVideoTrans-based fork.

Deliver:
- clean fork;
- ckb target;
- Sorani normalization;
- existing-SRT path;
- SRT export;
- initial Gemini provider.

## Phase 2 — Contextual translation
Deliver:
- Movie Bible;
- scene batching;
- glossary;
- semantic interpretation;
- structured translation.

## Phase 3 — Professional subtitle adaptation
Deliver:
- CPS/CPL;
- line breaking;
- selective resegmentation;
- selective retiming;
- QC profiles.

## Phase 4 — Confidence and review
Deliver:
- semantic QA;
- linguistic QA;
- second-model verification;
- exception review queue.

## Phase 5 — Series continuity
Deliver:
- Series Bible;
- Season Bible;
- cross-episode terminology;
- recurring character/style memory.

## Phase 6 — Production hardening
Deliver:
- resumability;
- caching;
- crash recovery;
- observability;
- privacy controls;
- release automation.

## Phase 7 — Benchmark-driven model routing
Deliver:
- 500–1,000 item gold set;
- model comparison dashboard;
- prompt regression;
- automatic provider recommendations based on measured quality.

## Later
